# Releases

Releases are listed at
[github.com/beyond10x/inbox/releases](https://github.com/beyond10x/inbox/releases), and each
one has a section in
[`CHANGELOG.md`](https://github.com/beyond10x/inbox/blob/main/CHANGELOG.md).

A release is an annotated version tag (`0.6.1`) on a `main` commit whose checks are green, and
a GitHub Release whose notes say what changed and which limit stays open.

**No release attaches a binary.** Release 0.2.0 is the first whose source holds the binary
`inbox`. Build it from source ([first use](first-use.md)). No crate is published either.
